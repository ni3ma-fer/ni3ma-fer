## About

Data engineering student in France, finishing a double Master's at EFREI Paris: one in Data Engineering & AI, one in Fundamental Computer Science & AI.

Most of my work sits between the ingestion pipeline and the report: modelling messy operational data, writing the SQL and Python that reconciles it, then building the Power BI layer that people actually open every morning.
